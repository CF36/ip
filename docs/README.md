# Slowbro User Guide

Slowbro is a command-line task manager that helps you keep track of tasks,
deadlines, and events.

## Getting started

Start Slowbro and enter one command at a time. Slowbro saves your task list
automatically, so your tasks remain available the next time you start the
application.

## Command format

In this guide:

- `<description>`, `<date or time>`, and `<task number>` are values you provide.
- Text inside backticks represents a command or literal keyword.
- Task numbers refer to the numbers shown by `list`.
- Commands must be entered in lowercase.

## Adding tasks

### To-do tasks

Use `todo` to add a task without a deadline or time period.

**Format**

```text
todo <description>
```

**Example**

```text
todo Read chapter 5
```

Slowbro adds the task to your list and assigns it a task number.

### Deadlines

Use `deadline` to add a task that must be completed by a specific date or
time.

**Format**

```text
deadline <description> /by <date or time>
```

**Example**

```text
deadline Submit assignment /by Friday
```

### Events

Use `event` to add an activity with a starting and ending time.

**Format**

```text
event <description> /from <start> /to <end>
```

**Example**

```text
event Team meeting /from Monday 2pm /to Monday 4pm
```

## Viewing tasks

### List all tasks

Use `list` to display every task in your task list.

```text
list
```

Each task is shown with its task number. Use this number when marking or
deleting a task. Task numbers start from `1` and match the numbers displayed by
`list`.

### Find tasks

Use `find` to search for tasks whose descriptions contain a keyword.

**Format**

```text
find <keyword>
```

**Example**

```text
find assignment
```

Slowbro displays all matching tasks.

The search is case-insensitive and matches keywords anywhere in the task
description. For example, `find assign` also matches `Submit assignment`.

## Updating tasks

### Mark a task as done

Use `mark` followed by the task number.

**Format**

```text
mark <task number>
```

**Example**

```text
mark 2
```

### Mark a task as not done

Use `unmark` followed by the task number to change a completed task back to
an incomplete task.

**Format**

```text
unmark <task number>
```

**Example**

```text
unmark 2
```

## Deleting tasks

Use `delete` followed by the task number to remove a task.

**Format**

```text
delete <task number>
```

**Example**

```text
delete 2
```

> [!WARNING]
> Deleting a task removes it from your task list. Check the task number
> carefully before entering the command.

## Exiting Slowbro

Use `bye` to close the application.

```text
bye
```

## Common errors

- Ensure that every command has the required arguments.
- Do not leave task descriptions, deadlines, or event times empty.
- Use a valid task number shown by `list`.
- For deadlines, include `/by`.
- For events, include both `/from` and `/to`.

## Data storage

Slowbro stores your tasks in `data/slowbro.txt` relative to the directory where
the application is run. Do not edit this file manually unless you know the
expected format.

Slowbro saves your task list automatically whenever you add, update, or delete
a task. No separate save command is required.

## Command summary

| Action | Format | Purpose |
| --- | --- | --- |
| Add to-do | `todo <description>` | Add a task |
| Add deadline | `deadline <description> /by <date or time>` | Add a deadline |
| Add event | `event <description> /from <start> /to <end>` | Add an event |
| List tasks | `list` | Display all tasks |
| Find tasks | `find <keyword>` | Search task descriptions |
| Mark done | `mark <task number>` | Mark a task as complete |
| Mark not done | `unmark <task number>` | Reopen a task |
| Delete task | `delete <task number>` | Remove a task |
| Exit | `bye` | Close Slowbro |
